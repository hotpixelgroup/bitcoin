One node alone proves nothing.

On a private chain of one, any rule appears to work, because nobody is present to disagree. So every experiment gets a second node.

Predict.

Before anything runs, you say what you think will happen. Ten ready-made experiments start you off, from "are your coins in your wallet?" to "how much mining power does a rule change need?". No AI and no compiler needed.

Observe.

Your change is compiled in a sandbox and run beside an unmodified node. You see which blocks each one refused, and the reason it gave.

Understand.

Each outcome comes with what it would mean on a real network, written by people, not by the AI, with its sources. Ten statements, answered before and after, show you what changed in your own thinking.

Install the lab.

macOS or Linux. Windows users can run it in WSL2. It starts on regtest, a private chain that exists only on your machine.

One line

curl -fsSL https://github.com/hotpixelgroup/bitcoin/releases/latest/download/install.sh | sh

The installer published with the latest release. It installs that release, checks the ready-made node against its published SHA-256, and asks before running anyone else's installer. The first build takes several minutes or longer, depending on your machine.

Read the installer first 
curl -fsSL https://github.com/hotpixelgroup/bitcoin/releases/latest/download/install.sh -o install.sh
less install.sh
VIBES_DRY_RUN=1 sh install.sh

Then run

~/bitcoin-vibes/vibes

The console opens in your browser. The ready-made experiments need nothing more. Requests in your own words need Claude Code, signed in with claude auth login.

Prefer the Mac app?

A launcher that prepares the node and reports progress in your browser. It is not notarised by Apple yet, so macOS asks you to allow it the first time.

Run with Docker

git clone -b master https://github.com/hotpixelgroup/bitcoin.git
cd bitcoin
docker compose -f contrib/vibes/docker-compose.yml up --build

Open the link from the logs. The container keeps its own Claude Code sign-in. In Docker a proposal is compiled only after you have reviewed it.

Already installed?

Use “Check for and take updates” in the console. Like Bitcoin Core, the lab never updates by itself.

A few things worth knowing.

Is the browser demo a real Bitcoin node?

No. It runs no AI and no node. Its ready-made experiments replay results that were recorded from real runs of the lab, so what you read there is what two real nodes did. Install Bitcoin Vibes to run your own.

Does a fresh install change Bitcoin's rules?

No. A fresh install has Bitcoin Core's consensus rules exactly; an automated check fails our build if the node source differs from upstream in anything but the name it reports. Every change after that is one you asked for.

Is it safe to let an AI rewrite a node on my machine?

The agent can read and edit files in its own copy of the source and nothing else: no commands, no network. What it writes is compiled and run inside an operating-system sandbox. That is confinement, not a guarantee, and you should still read the change. Where no sandbox is available, which includes Docker, the lab says so and compiles nothing until you have reviewed it.

What do the checks prove?

That the change compiles, which of Bitcoin Core's unit tests still pass, and what an unmodified node did with a limited set of blocks and transactions. A change to something those checks never exercise shows no difference. None of it proves a change is safe on a real network.

Can I use it on the real Bitcoin network?

It is a lab, not a wallet. On the real network you must confirm deliberately, the lab refuses to start any build whose comparison found a consensus difference, and the wallet stays disabled unless you switch it on. Do not point a wallet holding real funds at an experimental node.

Can I share an experiment?

You share the words you typed, never code. Because words are instructions to an AI agent, the recipient's lab treats them as untrusted: it shows them first, never applies them automatically, and the agent that reads them can only edit files.

What does it cost?

The software is free and MIT licensed. The ready-made experiments and the demo make no AI calls. Each request in your own words is a Claude Code session billed by your provider.

Is this an alternative to Bitcoin Core or Bitcoin Knots?

No. The tagline is a joke. Nothing made here is offered to Bitcoin Core, whose own policy requires a human author who understands every change. Bitcoin Vibes is a way to see why changing a node does not change Bitcoin.
