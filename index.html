A few things worth knowing.

Is the browser demo a real Bitcoin node?

No. GitHub Pages hosts static files. The demo simulates the workflow, including failure recovery, without contacting an AI or running a node. Install Bitcoin Vibes to generate real code and run the local experiment lab.

Does a fresh install change Bitcoin’s rules?

A fresh install preserves upstream consensus rules. Your experiments determine subsequent changes. The console starts on regtest, a private test network.

What does a passing experiment prove?

The recorded checks passed for that candidate. Unit tests and a general regtest check do not prove every requested behavior. Wish-specific checks report expected and observed values separately. Compatibility detection is a heuristic and does not prove mainnet compatibility.

What happens if activation fails?

The console waits for RPC readiness and attempts to restart the previous executable when available. Revert adds a source commit and can build and verify it. Executable rollback does not undo chain data changes.

Can I share an experiment?

Share the original request as a link or vibe1 token. Recipients review the words and ask their own agent to generate a proposal. Shared requests never execute automatically.

What does it cost?

The software is free and MIT-licensed. Real requests use your Claude Code account and are billed by your provider. The console shows actual session cost when the engine reports it. The browser demo and local mock engine make no AI calls.

Can it use my existing wallet?

The console uses an isolated data directory. Playground transaction scenarios create temporary wallets on disposable regtest nodes. They do not send real bitcoin. AI code changes and unrestricted agent mode still require your judgment.

Is this a joke?

The node is real. The text area is real. The divine authority is between you and your compiler.
