Import or share a request
A shared decree carries words, not executable code. Imported requests are displayed for your review and never run automatically.
How does an experiment work?
The agent works in an isolated checkout. Review the proposal, then apply it to your source. Builds run unit tests and a disposable regtest scenario before activation. Wish-specific checks appear separately; general checks do not prove every requested behavior.
What if an experiment fails?
Your running release stays separate from the build output. Inspect the error and logs, refine the request, retry the build, or revert its source commit. Failed activation attempts restore the previous executable when available. Executable rollback does not undo changes to chain data.
What does compatibility impact mean?
Source patterns and sensitive file paths flag possible changes to Bitcoin rules. They can miss changes or flag harmless edits. Neither a passing test nor an empty warning proves mainnet compatibility.

Install or update the local console
